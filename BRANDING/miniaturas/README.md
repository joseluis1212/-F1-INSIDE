# Miniaturas

Ejemplos en [png](png/); son **maquetas internas**, no piezas listas para publicar. Los tiempos y etiquetas son ilustrativos y deben sustituirse; revisar cada titular frente al guion y actualizar el nombre provisional. La plantilla SVG tiene textos convertidos a trazados: editar en un programa vectorial sustituyendo los grupos de texto; las guías son orientativas y deben eliminarse al exportar.

1. Una sola idea, máximo 2–4 palabras relevantes cuando sea posible; contraste alto y lectura móvil.
2. Imagen propia o licenciada, con permiso para uso comercial y miniaturas. Nunca copiar una foto, captura o logo oficial sin derechos.
3. Evitar rostros sintéticos realistas que representen falsamente hechos o declaraciones; revelar contenido alterado cuando corresponda.
4. Exportar 16:9 para video y comprobar requisitos vigentes en [YouTube](https://support.google.com/youtube/answer/72431?hl=es-419). Probar dos conceptos honestos y medir CTR junto con retención; no prometer lo que no cumple el video.

**Control de calidad:** las etiquetas de duración incluidas en los ejemplos son ficticias y pueden competir visualmente con el indicador de duración de YouTube. Eliminar duración y etiquetas de ronda antes de publicar; comprobar también que el titular corresponda al video y siga vigente. El ejemplo de curiosidad no es una miniatura vertical de Shorts.
