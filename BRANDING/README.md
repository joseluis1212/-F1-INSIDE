# Identidad visual · borrador

La marca debe transmitir velocidad, claridad y criterio editorial, sin parecer oficial. Todos los archivos que contienen «F1 INSIDE» son **bocetos internos pendientes de revisión de marca**; no subirlos como identidad comercial sin autorización o cambio de nombre. El isotipo geométrico no reproduce el logo oficial, pero también requiere comprobación de similitud.

- [Logos vectoriales](logo/) y [exportaciones PNG](png/)
- [Miniaturas y plantilla](miniaturas/README.md)

El banner, el avatar y los ejemplos de miniaturas son maquetas: sus tiempos, etiquetas y fechas son ilustrativos, no compromisos ni resultados publicados. Sustituirlos después de aprobar nombre y contenido.
