# Edición

Montar primero la narración; añadir gráficos originales, imágenes autorizadas y ritmo al servicio de la idea. Insertar subtítulos revisados, fuentes en descripción y capítulos cuando aporten valor. Exportar como mínimo 1080p para largos y vertical para Shorts; comprobar audio, ortografía, derechos y coherencia de miniatura. No producir presentaciones repetitivas con escasa aportación original.
